Checks performed and not performed

Performed

  • File type detection (Shopify product CSV, inventory CSV, other spreadsheet) from the header row
  • Shopify column names (current and legacy template names): required, misspelled, differently spelled, duplicated and unrecognised columns
  • URL handles: missing, invalid characters, a product's rows split up, rows that cannot be linked to a product (repeated handles for variants and images are allowed)
  • Titles and product details across a product's rows (blank product columns on variant and image rows are allowed)
  • Options and variants: missing option names or values, duplicate option names, duplicate variants
  • Prices: valid number, negative, zero, decimals, plain-number format, compare-at price against price
  • Identifiers: missing and duplicate SKUs, SKU format, possible lost leading zeros; Barcodes lists (semicolon-separated, escapes, 20-barcode limit, type prefixes, GS1 checks for entries typed gtin/upc only), Barcode and Barcodes in one file, check digits in the older single-barcode columns
  • Image URLs (text only: https, spaces, credentials, local paths) and the 250-image limit
  • Inventory: linked tracker/policy/fulfillment columns, whole-number quantities, quantities on untracked variants
  • Documented values for Published, Status (and a value in every product's Status when the column is included), Gift card, Requires shipping, Charge tax, inventory tracker/policy, weight unit and packed dimension unit
  • Packed product dimensions: all four or none per variant, length/width/height positive and below 2,000,000,000, saved dimensions cleared by blank cells or by Requires shipping = FALSE
  • Metafield and Option LinkedTo columns with values (need store definitions or a product category)
  • Collection column: 255-character limit; collections that may be created
  • Formula-like values (spreadsheet safety) and their effect on cleaned.csv

Not performed or not verifiable

  • Live validation in Shopify: the file was not uploaded to or imported into any store.
  • Changes to existing products, options and variants: no current store export was supplied.
  • Image URLs were not opened: whether they exist, are public, and are valid images of an accepted size is unknown.
  • Metafield, market price, Google Shopping and Option LinkedTo columns are recognised, but their values are not validated, and the store's metafield definitions and product categories cannot be seen (filled metafield and LinkedTo columns are reported as risks). Variant metafield columns are reported because Shopify's product CSV does not support them.
  • Whether the named collections exist in the store, and whether barcode types other than gtin and upc are accepted by the CSV importer.
  • Whether every alternative column spelling (current or legacy name) is accepted by Shopify's live importer.
  • Plan-specific and variant-count limits, product category values, tax codes, theme templates and location names.
  • Commercial correctness: prices, supplier data, and whether barcodes belong to the products.

Assumptions this review does not make

  • That Shopify will accept this file or that the import will have no side effects.
  • That products or variants missing from this file should be deleted from the store.
  • That a repeated URL handle is a duplicate product (repeated handles are normal for variants and images).
  • That a blank cell and an omitted column have the same effect (they do not with overwrite).
  • That a valid barcode check digit proves the barcode belongs to the product.
  • That supplier prices, stock levels or descriptions are correct.
  • That this automated review replaces a person's review before import.

Shopify import limitations

  • Rules reflect Shopify's documentation as reviewed on 2026-10-29. Shopify can change its importer and templates at any time.
  • With 'Overwrite products with matching handles', blank values in included columns overwrite store values; columns that are not included keep store values. Without overwrite, products with existing handles are ignored.
  • Changing option values deletes and recreates variant IDs; apps, feeds and integrations that refer to variant IDs can break.
  • Product CSVs and inventory CSVs are separate imports. The product CSV's inventory quantity applies to single-location stores.
  • Shopify downloads images from public https URLs during import; this review did not open them.
  • This review does not produce an import-approved file. cleaned.csv is a review copy: when formula-like values were made spreadsheet-safe (leading apostrophe) it must not be imported as it is. Shopify imports CSV files, not Excel files; do not open and re-save a CSV in Excel (identifiers and leading zeros can change).
  • Back up the store's products (product export) and test the import with a few products first.

Limitations

  • Automated checks only find the problem types listed in this report. A row without flags has passed these checks; it has not been proven correct.
  • Nothing is verified against external sources (supplier data, barcode registries, the live shop). An EAN/GTIN with a valid check digit is not necessarily registered to this product.
  • Prices are checked as numbers (valid, not negative, not zero, at most two decimals); they are not checked for commercial plausibility.
  • Identifiers that were already damaged before the file reached this tool (lost leading zeros, scientific notation) cannot be restored; they are only flagged.
  • Excel formulas are never executed. The value Excel last saved is used. Excel display formatting (currency, percent, custom date formats) is not reproduced, except zero-padded number formats such as 00000; dates are written as YYYY-MM-DD.
  • Duplicate, capitalization and lost-leading-zero findings marked 'judgment' are heuristics that need a person to decide.
  • Files that are not UTF-8 must be given an explicit --encoding; the tool does not guess encodings.
