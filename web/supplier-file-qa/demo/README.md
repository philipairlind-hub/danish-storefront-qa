# SupplierPreflight synthetic conversion example

**All data is generated for demonstration.** The supplier file, conversion, exception list, source lineage, QA report and delivery ZIP are synthetic.

This is a reproducible example from the existing engine on 9 November 2026. It is not evidence of a customer order or Shopify import acceptance, and the displayed decisions rely on an operator-agreed mapping.

Open index.html to see before/after tables and download the exact output artifacts. Read delivery/DELIVERY_NOTE.md for the documented conditions before controlled import testing.

The buyer-facing service, scope and marketplace checkout options are described at https://philipairlind-hub.github.io/danish-storefront-qa/supplier-file-qa/.
